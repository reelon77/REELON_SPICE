# 面试素材 · 牛顿收敛性与直流工作点

> 归档日期:2026-08-05(Day 4 收官讨论)。配套实验数据见讲义 artifact
> "多维牛顿与二极管"的迭代实录表;实现见 `src/solver/newton.cpp`。
> 用途:被问"牛顿一定收敛吗 / 你的求解器怎么保证收敛 / 不收敛怎么办"时的分层答案。

## 一句话总纲

对单二极管电路,收敛性**可证明**(单调 + 凸 ⇒ Newton–Fourier 全局单调收敛);
对一般非线性电路,收敛保证**理论上不存在**(多工作点是物理真实),
所以 max_iter 保险丝 + 同伦延拓是工程对数学事实的承认,不是偷懒。

## 第一层:本项目电路,收敛有证明

化到标量方程(三维 MNA 消去线性行严格等价,消元与牛顿可交换):

    g(v) = Is·(e^(v/Vt) − 1) + (v − Vs)/R = 0

两条性质:

    g′(v) = (Is/Vt)·e^(v/Vt) + 1/R > 0     严格单调增 ⇒ 根存在唯一(g(0)<0<g(Vs))
    g″(v) = (Is/Vt²)·e^(v/Vt) > 0          严格凸

**Newton–Fourier 论证(一行)**:凸函数的切线在图像下方,T(v) ≤ g(v),
故切线零点 x₁ 满足 g(x₁) ≥ T(x₁) = 0,即 x₁ 落在根的右侧;
其后每步都停在右侧且严格左移 ⇒ **任意初值,一步过后单调收敛,不发散不振荡**。

**实测就是定理的逐帧回放**(v⁰ = 0,tol 1e-12):
第一步 g_eq ≈ Is/Vt ≈ 4e-11,解直接跳到 ≈5V(冲到根右侧);
之后爬坡段每步精确下降 ≈ 一个 Vt(推导:陡峭区 g/g′ ≈ Vt),
(5 − 0.574)/0.026 ≈ 170 ⇒ 实测 **177 次**;末段二次收敛,正确位数逐轮翻倍
(3→4→8→12 位)。初值 v⁰ = 0.9 时 18 次。

## 第二层:真正的风险是溢出,不是发散

本电路最大指数 e^(5/Vt) ≈ e^193 ≈ 5×10⁸³ < double 上限 1.8×10³⁰⁸,装得下;
Vs = 20V ⇒ e^774 = inf,一轮 NaN 全场。
**limiting/阻尼的第一动机是驯服指数,其次才是救收敛**。
本项目有意不实现(不扩科),但机理能讲:对 Δv 设上限(如 2Vt)或对二极管电压做
对数域限幅,等价于阻尼牛顿,以牺牲二次收敛换全局稳健。

## 第三层:一般电路,收敛保证理论上不可全有

1. **单调网络**(所有器件 I–V 特性单调,R/二极管属之):
   Minty/Duffin 单调算子理论 ⇒ 解唯一;阻尼牛顿基本必达。理论友好区。
2. **有源器件 + 反馈**:F 不再单调,**多个直流工作点是物理真实**——
   SRAM 单元/锁存器靠双稳态吃饭,方程组真有三个解(两稳一亚稳),
   收敛到哪个取决于初值,全局收敛定理不可能存在。
3. **工业对策 = 同伦/延拓法族**:把"有好解的问题"连续变形到目标问题,牵着牛顿走——
   - gmin stepping:每个结点并大电导到地(强对角占优),逐步撤掉
   - source stepping:源从 0 缓升到额定值,上一步解作下一步初值
   - pseudo-transient:借瞬态积分的 A-稳定性滑到直流工作点
   收敛失败是 EDA 求解器团队的日常主粮——这正是 Engine 岗存在的原因(求职话术钩子)。

## 追问预案

- "为什么你的实现不做 limiting?" → 时间盒决策 + 本电路有收敛证明,数值安全边界
  (e^193 < DBL_MAX)是设计时验算过的;演进路径清楚(Δv 限幅一处改动)。
- "怎么验证收敛判据?" → ∞ 范数逐分量判(每个未知量各自稳住),不用 2 范数
  (含义随维度漂移);烟囱测试:纯线性电路 2 轮收敛且答案不变,专守清零重组装。
- "迭代 177 次是不是太多?" → 反问式回答:不是 bug 是指数爬坡的固有速率(每步 Vt),
  真 SPICE 靠 limiting 砍到 ~20 次;能当场推 g/g′ ≈ Vt。
