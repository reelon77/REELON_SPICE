# Obsidian 常用命令速查（macOS）

万能入口：**⌘P 命令面板**——记不住快捷键时搜命令名即可，所有功能都能从这里触达。

---

## 1. 高频快捷键

### 文件与导航

| 快捷键 | 功能 |
|---|---|
| ⌘O | 快速切换/新建笔记（输入不存在的名字直接回车 = 新建） |
| ⌘P | 命令面板 |
| ⌘N | 新建笔记 |
| ⌘⇧F | 全库搜索 |
| ⌘F | 当前笔记内搜索 |
| ⌥⌘← / ⌥⌘→ | 后退 / 前进（浏览历史） |
| ⌘E | 编辑 / 阅读模式切换 |
| ⌘, | 设置 |
| ⌘W | 关闭当前标签页 |
| ⌘T | 新标签页 |

### 编辑

| 快捷键 | 功能 |
|---|---|
| ⌘B / ⌘I | 加粗 / 斜体 |
| ⌘K | 插入外部链接 `[]()` |
| ⌘D | 删除当前行 |
| ⌥↑ / ⌥↓ | 上移 / 下移当前行 |
| ⌘] / ⌘[ | 增加 / 减少缩进 |
| ⌘/ | 切换注释 `%% %%` |
| ⌘⏎ | 切换任务勾选状态 |

### 面板

| 快捷键 | 功能 |
|---|---|
| ⌘⇧E | 聚焦文件列表 |
| ⌥⌘F | 悬浮预览链接（按住 ⌘ 悬停也可） |
| ⌘G | 打开关系图谱 |

> 以上部分快捷键可能因版本或个人配置不同，冲突时去 设置 → 快捷键 里搜命令名确认或重绑。

## 2. Obsidian 特有语法

这些是 Obsidian 在标准 Markdown 之上扩展的部分，也是它的核心价值所在。

### 双链与嵌入

```
[[笔记名]]              链接到另一篇笔记
[[笔记名|显示文字]]      自定义显示文字
[[笔记名#标题]]          链接到某个标题
[[笔记名#^块ID]]         链接到某个块（输入 ^ 后自动补全）
![[笔记名]]             嵌入整篇笔记内容
![[图片.png]]           嵌入图片
![[笔记名#标题]]         只嵌入某一节
```

输入 `[[` 会自动弹出补全，这是 Obsidian 最常用的操作，没有之一。

### 标签与属性

```
#标签  #嵌套/子标签

---
tags: [线性代数, 数值计算]
aliases: [LU, 三角分解]
---
```

文件开头 `---` 包裹的是 frontmatter（属性区），`aliases` 定义别名后，`[[LU]]` 也能链到本篇。

### Callout（提示块）

```
> [!note] 标题
> 内容

> [!theorem]- 折叠的定理块（减号 = 默认折叠）
> 内容
```

常用类型：`note` `tip` `warning` `example` `quote` `abstract`——写数学讲义时用 `> [!theorem]`、`> [!proof]` 这类自定义名也可以，样式回退到 note。

### 数学公式

```
行内：$a_{kk} \neq 0$
独立：
$$PA = LU$$
```

Obsidian 内置 MathJax，LaTeX 直接渲染——你写讲义类笔记的主场。

## 3. 常用命令面板命令（⌘P 后搜索）

| 搜索关键词 | 功能 |
|---|---|
| `move` | 移动文件到其他文件夹 |
| `rename` | 重命名（所有 `[[链接]]` 自动更新） |
| `template` | 插入模板（需启用核心插件 Templates） |
| `daily` | 打开今日日记 |
| `export pdf` | 导出为 PDF |
| `copy path` | 复制文件路径 |
| `toggle live preview` | 切换实时预览 / 源码模式 |
| `fold all` | 折叠全部标题 |
| `split right` | 向右分屏 |
| `open in default app` | 用系统默认程序打开（如 VSCode） |

## 4. 建议开启的核心插件

设置 → 核心插件：

- **模板（Templates）**：定理笔记、文献笔记做成模板一键插入
- **大纲（Outline）**：右侧栏显示标题目录，长讲义必备
- **反向链接（Backlinks）**：看哪些笔记引用了当前笔记
- **日记（Daily notes）**：按日期记录
- **幻灯片（Slides）**：`---` 分隔的笔记直接放映

第三方插件里对数学笔记最有用的两个：**Latex Suite**（LaTeX 快捷输入，`aii` → `a_{i}` 这类 snippet）和 **Excalidraw**（手绘示意图）。
