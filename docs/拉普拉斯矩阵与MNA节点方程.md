# 拉普拉斯矩阵与节点方程:从电路图到 $Gv=I$

回答三个问题:① stamp 规则 `G[i][i]+=g, G[j][j]+=g, G[i][j]-=g, G[j][i]-=g` 从哪来;② 如何从电路图列出方程;③ 为什么必须删掉地节点的行和列。

先把电路翻译成数学语言:**电路图就是一张带权无向图**。顶点是电路节点,每个顶点带一个未知标量 $v_i$(电位);电阻是带权边,权是**电导** $g = 1/R$(单位西门子);电流源是从外部往顶点注入流量。整套方程只用两条公理:

- **欧姆定律**:边 $(i,j)$ 上从 $i$ 流向 $j$ 的电流为 $g\,(v_i - v_j)$;
- **KCL(基尔霍夫电流定律)**:每个顶点,流出电流之和 = 外部注入的电流。这就是离散的流量守恒(散度定理)。

阅读电路图的最小约定:

```
 ●          节点(图的顶点),同一条导线上的所有点是同一个节点,电位相同
─[R]─       电阻(带权边)
─(↑)─       电流源,箭头方向 = 电流注入方向
 ⏚ / ┴      地:被钦定为参考的那个节点
```

## 1. stamp 规则的来源(问题 ①)

只看一条边:节点 $i$、$j$ 之间接一个电导为 $g$ 的电阻。

```
            i(i→j) = g·(vᵢ − vⱼ)
        ─────────────────────────▶
   ●────────────[ g ]────────────●
   vᵢ                            vⱼ
```

对节点 $i$ 写 KCL 时,这条电阻贡献的流出电流按未知量展开:

$$g\,(v_i - v_j) \;=\; \underbrace{+g}_{\text{第 } i \text{ 行对角}}\, v_i \;\; \underbrace{-\,g}_{\text{第 } i \text{ 行第 } j \text{ 列}}\, v_j$$

对节点 $j$ 写 KCL 时,同一条电阻的流出电流方向反过来,整体取反:

$$g\,(v_j - v_i) \;=\; +g\, v_j \; -\, g\, v_i$$

所以**一个电阻恰好在系数矩阵上落下 4 个数**,构成一个 $2\times 2$ 图案:

$$\begin{array}{c|cc} & \text{列 } i & \text{列 } j \\ \hline \text{行 } i & +g & -g \\ \text{行 } j & -g & +g \end{array}$$

这就是 stamp(印章)这个名字的由来:每个器件往矩阵上"盖"一个固定图案,整个矩阵是所有边的印章**叠加**(`+=`)出来的——对应代码

```cpp
G[i][i] += g;  G[j][j] += g;
G[i][j] -= g;  G[j][i] -= g;
```

注意这枚印章**每行之和本身就是 0**。叠加保持这条性质,所以无论电路怎么接,总矩阵行和恒为零——奇异性在单条边这一步就已注定。

## 2. 从电路图列方程:一个算到底的例子(问题 ②)

三个顶点:节点 1、节点 2、节点 0(地)。一个 $1\,\mathrm{A}$ 电流源把电流从地抽出、注入节点 1;三个电阻 $R_1 = 1\,\Omega$、$R_2 = 2\,\Omega$、$R_3 = 1\,\Omega$,对应电导 $g_1 = 1$、$g_2 = 0.5$、$g_3 = 1$。

```
        节点1 v₁              节点2 v₂
   ┌──────●──────[R₂=2Ω]──────●
   │      │      g₂=0.5       │
  (↑)   [R₁=1Ω]             [R₃=1Ω]
  1A     g₁=1                g₃=1
   │      │                   │
   └──────●───────────────────┘
        节点0(地) v₀
          ⏚
```

对每个顶点写 KCL:经每条邻边流出的电流之和 = 外部注入。节点 1 有两条邻边($R_1$ 通向地、$R_2$ 通向节点 2),外部注入 $1\,\mathrm{A}$:

$$\begin{aligned} \text{节点 1:}\quad & g_1(v_1 - v_0) + g_2(v_1 - v_2) = 1 \\ \text{节点 2:}\quad & g_2(v_2 - v_1) + g_3(v_2 - v_0) = 0 \\ \text{节点 0:}\quad & g_1(v_0 - v_1) + g_3(v_0 - v_2) = -1 \quad (\text{源从地抽走 } 1\,\mathrm{A}) \end{aligned}$$

代入数值,按未知量 $(v_0, v_1, v_2)$ 整理成 $Gv = I$:

$$\begin{pmatrix} 2 & -1 & -1 \\ -1 & 1.5 & -0.5 \\ -1 & -0.5 & 1.5 \end{pmatrix} \begin{pmatrix} v_0 \\ v_1 \\ v_2 \end{pmatrix} = \begin{pmatrix} -1 \\ 1 \\ 0 \end{pmatrix}$$

结构一目了然:**对角元 = 该顶点所有邻边电导之和,非对角元 = 边电导取负**。这正是图论的拉普拉斯矩阵 $L = D - A$(度矩阵减邻接矩阵,边权换成电导)。每行之和为 $0$,即

$$G\,\mathbb{1} = 0, \qquad \mathbb{1} = (1,1,\dots,1)^{\mathsf T},$$

$\mathbb{1} \in \ker G$,零空间非平凡,$\det G = 0$:**$G$ 精确奇异**——不是数值病态,是恒等意义上的奇异。

## 3. 为什么删掉地的行和列(问题 ③)

**先澄清一个误读:地并不会造成某一行全为零。** 奇异的真正原因是**各行线性相关**:上例中

$$\text{行 0} = -(\text{行 1} + \text{行 2}),$$

右端项同样满足 $-1 = -(1 + 0)$。这不是巧合:每条电阻的电流 $g(v_i - v_j)$ 在 $i$ 的方程里出现一次、在 $j$ 的方程里以相反符号再出现一次,把**所有** KCL 方程相加必然逐项抵消,恒等于零。所以 $n$ 个方程只有 $n-1$ 个独立。物理话说:源流出的电流最终必然全数流回地,地的守恒方程是其余方程的推论,**不含新信息**。

方程冗余一个,解就自由一个维度:若 $v$ 是解,则 $v + c\,\mathbb{1}$ 也是解——所有电位平移同一常数,每条边的电位差 $v_i - v_j$ 不变,电流不变。这与"势函数差一个常数""Neumann 边条件下 Poisson 方程解不唯一"是同一件事。

解决方式也一样——**固定规范**:钦定 $v_0 = 0$。于是:

- **删列 0**:$v_0 = 0$,乘它的系数全部无效;
- **删行 0**:地的方程本来就冗余,直接丢弃。

$$\begin{pmatrix} \require{cancel}\cancel{2} & \cancel{-1} & \cancel{-1} \\ \cancel{-1} & 1.5 & -0.5 \\ \cancel{-1} & -0.5 & 1.5 \end{pmatrix} \;\longrightarrow\; \begin{pmatrix} 1.5 & -0.5 \\ -0.5 & 1.5 \end{pmatrix} \begin{pmatrix} v_1 \\ v_2 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$

降阶后的矩阵(**grounded Laplacian**)行和不再为零——与地相连的行丢掉了通向地的 $-g_1$、$-g_3$。它对称、对角占优;只要电路连通(每个节点到地有电阻通路),它还是**对称正定**的,LU/Cholesky 分解畅通无阻,解唯一。

解这个 $2\times 2$ 系统:

$$v_1 = 0.75\,\mathrm{V}, \qquad v_2 = 0.25\,\mathrm{V}.$$

把解标回电路验证守恒:

```
        v₁=0.75V              v₂=0.25V
   ┌──────●──────[R₂]──────────●
   │      │    → 0.25A         │
  (↑)   [R₁]                 [R₃]
  1A    ↓ 0.75A              ↓ 0.25A
   │      │                    │
   └──────●────────────────────┘
     地:流回 0.75 + 0.25 = 1A,恰好等于源抽走的 1A ✓
```

节点 1:流出 $0.75 + 0.25 = 1\,\mathrm{A}$ = 注入 ✓;节点 2:流入 $0.25\,\mathrm{A}$ = 流出 ✓。

## 4. 落到实现与测试

实际 MNA 组装时,地节点根本不进矩阵——不是先建 $n \times n$ 再删行列,而是 stamp 时遇到地节点就跳过对应行列。矩阵维度从一开始就是 $n - 1$。

两条可直接写进 GTest 的用例:

1. **守恒性测试**:组装一次含地的完整 $G$,断言每行(和每列,矩阵对称)之和为 $0$——验证 stamp 的对称性与守恒性;
2. **端到端测试**:本讲义的例题,删地后的 $2\times 2$ 矩阵交给 LU 求解器,断言 $v_1 = 0.75$、$v_2 = 0.25$——固定答案,手算可验。

符号约定备注:电流方向、源的正负都只是约定,选反了整组方程同乘 $-1$,解不变。
