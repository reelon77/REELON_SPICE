一个具体电路,和它的 MNA 方程

就用你 Day 3 闸门电路:V1 = 10V,R1 = 1kΩ,R2 = 4kΩ。先看电压源怎么把系统从 2 维撑到 3 维,再往里加一个电流源,看它为什么只动右端项 b。

1电路图

2未知量

2 个节点 + 1 个电压源,所以未知量是 2 + 1 = 3 个:

x = [ v₁, v₂, i_V1 ]ᵀ

前两个是节点电压(Nodal Analysis 的老未知量),第三个是流过电压源的电流——它就是 MNA 里 “Modified” 加出来的那一维,数学上是约束 v₁ = 10 的拉格朗日乘子。

3逐条写方程

每个非参考节点写一条 KCL(流出电流之和 = 0),每个电压源写一条约束:

KCL @ 节点1(v₁ − v₂)/R1 + i_V1 = 0
KCL @ 节点2(v₂ − v₁)/R1 + v₂/R2 = 0
约束 @ V1v₁ = 10

注意第一条:节点 1 上没有别的出路,R1 的电流全部由 i_V1 平衡。第三条不是 KCL,它是电压源硬性规定的等式约束——正因为写不成 "电流 = f(电压)" 的形式,纯节点法才容纳不了它。

4矩阵形式 Ax = b

把上面三条按 x = [v₁, v₂, i_V1]ᵀ 整理,每一项的颜色标出它是哪个器件 stamp 进去的:

1/R1−1/R11 −1/R11/R1+1/R20 100 v₁v₂i_V1 = 0010
0.001−0.0011 −0.0010.001250 100 v₁v₂i_V1 = 0010
R1 的 stamp(2×2 对称块) R2 的 stamp(只碰 (2,2),因为另一端接地) V1 的 stamp(B 列 + Bᵀ 行 + b)

看结构:左上 2×2 是纯电阻的电导矩阵 G(对称);V1 贡献了第 3 列(i_V1 进入节点 1 的 KCL)和第 3 行(约束方程),右下角是 0——这就是鞍点结构,也是 LU 要做部分主元的原因:不换行的话第 3 步主元可能落在这个 0 上。

5解

未知量值验证
v₁10 V约束方程直接给出
v₂8 V10 × 4k/(1k+4k) 分压 ✓
i_V1−2 mA−10/(1k+4k) ✓

这就是你的端到端闸门:三个断言 v₁ = 10、v₂ = 8、i_V1 = −0.002。

6变体:加一个电流源,只有 b 会动

节点 2 的 KCL 多了一个常数项(流入 1mA,移到右边):

KCL @ 节点2(v₂ − v₁)/R1 + v₂/R2 = 0.001
0.001−0.0011 −0.0010.001250 100 v₁v₂i_V1 = 00.00110
I1 的 stamp——整个系统里它只碰了这一个数

矩阵 A 一个字没改,维度也没变。解变成 v₂ = 0.011/0.00125 = 8.8 V,i_V1 = −1.2 mA。这就是两种源的本质差别落到代码上的样子:

器件碰 A 吗碰 b 吗加未知量吗
Resistor✓ (G 块)——
CurrentSource—✓ (±I₀)—
VoltageSource✓ (B 列 + Bᵀ 行)✓ (V₀)✓ (+1 维)
写 VoltageSource::stamp 之前,先手算一遍第 4 节那个 3×3,再让测试去对——闸门的三个断言就是这张表的最后一列。
