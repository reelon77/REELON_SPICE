## 二、本次课的教学范围（不要扩科）

### 1. 电路的数学抽象（10 分钟）
- 电路 = 图（graph）：节点 = 未知量（电压），支路上的器件 = 节点间的约束关系。
- 仿真器要解的问题：给定电路拓扑和器件参数，求所有节点电压 → 本质是解方程组。
- 地节点（ground，节点 0）= 电压参考零点，类似"固定规范/基准"，否则解不唯一（方程组奇异）。

### 2. 欧姆定律（15 分钟）
- 电阻上的电流是电压差的线性函数：`i = (v_a − v_b) / R`，其中 `G = 1/R` 叫电导。
- 方向约定：电流从 a 流向 b 为正。让用户注意符号约定的一致性——这是之后写代码时最容易出 bug 的地方。
- 小例子：`v_a=5V, v_b=2V, R=1kΩ → i=3mA`，让用户口算。

### 3. KCL 基尔霍夫电流定律（30 分钟，核心）
- 每个节点：流出电流之和 = 0（流量守恒，类比图论里的 flow conservation / 散度为零）。
- 对每个非地节点列一条 KCL 方程 → n 个节点 = n 条方程 = n 个未知电压。
- 独立电流源：往节点注入恒定电流，出现在方程右端（b 向量）。
- 小例子：单节点 + 电流源 + 两个接地电阻，列一条方程解出节点电压。

### 4. 分压电路手推（30 分钟，验证闸门）
电路：12V 电压源 → 节点1；R1=1kΩ 接节点1和节点2；R2=2kΩ 接节点2和地。

- 简化处理（今天够用）：电压源直接钉死 `v_1 = 12V`（已知量），只对节点 2 列 KCL：
  `(v_2 − 12)/1000 + v_2/2000 = 0` → `v_2 = 8V`
- **闸门标准**：用户能独立从零列出这条方程并解出 8V，能说清每一项是哪个器件贡献的、符号为什么是这样。
- 预告（只预告，不展开）：电压源的严谨处理会引入额外未知量（流过电压源的电流），这就是 MNA 的"扩展维"，本周 Day 3–4 学。

### 5. 通往矩阵形式的桥（20 分钟）
- 把 KCL 方程组写成 `Gv = b`：G 是电导矩阵（对称、对角占优），v 是节点电压向量，b 是电流源注入。
- 每个电阻对 G 的贡献有固定模式：接在节点 a、b 之间的电导 g，往 `G[a][a] += g, G[b][b] += g, G[a][b] -= g, G[b][a] -= g`——这就是 **stamp（盖章）** 的由来，是他代码里 `stamp()` 接口的数学本质。
- 让用户把分压电路（把 v1 也当未知量的两节点版本，暂时忽略电压源怎么处理）盖出 2×2 的 G 矩阵，感受"遍历器件、往矩阵里加数"的机械过程。
