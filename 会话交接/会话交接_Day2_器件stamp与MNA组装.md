### 核心设计：`stamp()` 多态

```
class Device {
public:
    virtual ~Device() = default;
    virtual void stamp(MnaSystem& sys) const = 0;
};
```

每种器件自己知道怎么把自己"盖章"进矩阵。**新增器件不改求解器**——
这是简历上"可扩展性"的核心卖点，面试必被追问（讲开闭原则）。

### 维数与节点映射（最容易卡的地方）

- 地节点固定为 **0**，**不进矩阵**（否则 G 是图拉普拉斯、行和为 0、必然奇异——
  用户 Day1 上午已经推过这个洞察，可以直接呼应）
- 节点 `k`（k ≥ 1）→ 矩阵下标 `k − 1`
- **电压源引入额外未知量**（支路电流），排在所有节点之后
- 总维数 `n = (节点数 − 1) + 电压源个数`

建议 `MnaSystem` 提供 `add_to_A(i, j, val)` / `add_to_b(i, val)` 这类辅助方法，
**内部处理"下标为地则跳过"**，这样各器件的 stamp 不用每个都写一遍 if(接地)。

### 各器件的 stamp 规则

设电阻接在节点 a、b 之间，电导 `g = 1/R`：

```
A(a,a) += g    A(b,b) += g    A(a,b) −= g    A(b,a) −= g
```

电流源 I（正方向定义为从 a 流向 b）：

```
b(a) −= I      b(b) += I
```

电压源 V（a 为正端），占用额外未知量下标 k：

```
A(a,k) += 1    A(b,k) −= 1        (KCL 里加上支路电流)
A(k,a) += 1    A(k,b) −= 1        (约束行：v_a − v_b = V)
b(k)   += V
```

### ⚠️ 预埋的坑（用户卡住时提示方向，别直接给答案）

1. **`stamp` 必须是 `+=` 不是 `=`** —— 用户在 Day1 上午课上**连错三次**，这是他的已知弱点。
   **第一个单测就要测"两个电阻共享同一节点，电导正确累加"**，不要等到整条链路跑完才发现。
2. 节点编号与矩阵下标差 1，地节点要跳过 —— off-by-one 重灾区。
3. 电压源的额外未知量下标别和节点下标撞了。
4. 对称性：电阻的 4 个 stamp 少写一个，矩阵就不对称了，但小电路可能仍能解出**看起来合理**的错误答案。
   → 建议加一个"G 子块必须对称"的单测。

## 三、验证用例（已用现有求解器实测，数值可信）

### 闸门电路

`V1 = 10V`（节点1 → 地），`R1 = 1kΩ`（节点1 → 节点2），`R2 = 4kΩ`（节点2 → 地）

未知量顺序 `[v1, v2, i_V1]`，组装出来的 MNA 系统应该是：

```
[  1e-3   −1e-3    1 ] [ v1   ]   [  0 ]
[ −1e-3   1.25e-3  0 ] [ v2   ] = [  0 ]
[  1       0       0 ] [ i_V1 ]   [ 10 ]
```

**实测解**（本文件写就前刚跑过）：

| 量 | 值 | 独立校验 |
|----|-----|---------|
| `v1` | 10 V | 等于源电压 |
| `v2` | **8 V** | 分压公式 `Vs·R2/(R1+R2)` = 8 ✓ |
| `i_V1` | −2 mA | 欧姆定律 `−Vs/(R1+R2)` = −2mA ✓ |

分解时 `perm = [2,1,0]`（首列最大元 `|1|` 在约束行，必然换行）——
顺带说明**为什么 MNA 矩阵必须选主元**：约束行的 1 比电导项（1e-3 量级）大几个数量级，
不选主元会拿 1e-3 当主元去消 1，误差放大三个数量级。这是个很好的面试素材。

### 建议的单测顺序（从小到大，别一上来就整条链路）

1. 单个电阻 stamp 进 2×2，检查 4 个位置的值和对称性
2. **两个电阻共享节点 → 该对角元是两个电导之和**（守住 `+=` 那个坑）
3. 电流源 stamp 到 b
4. 电压源扩展维：检查维数 = 节点数−1+源数，且约束行/列正确
5. 端到端：闸门电路 → `v2 == 8.0`

### 可选的第二个电路（若时间有余）

纯电阻 + 电流源，不含电压源，可验证"没有扩展维时"的路径。让用户自己设计并手推，
**你负责用求解器验算他的手推结果**，别反过来。
