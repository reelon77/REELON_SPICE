## 三、数学闸门（开工前先过）

### 1. 电容 + 后向欧拉

定义电容电压 `v = v(pos) - v(neg)`，电流正方向 `pos → neg`：

```text
i = C dv/dt
i_n = (C/dt)(v_n - v_{n-1})
    = G_eq v_n + I_eq

G_eq = C/dt
I_eq = -G_eq v_{n-1}
```

因此每个时间步中，电容等效为“电导 `C/dt` + 历史电流源”。必须能独立推出 A 的四个落点和 b 的两个符号，并用一个非零 `v_{n-1}` 对答数。

### 2. RC 后向欧拉递推

对 `Vs—R—C—ground`，令 `α = dt/(RC)`：

```text
v_n = (v_{n-1} + α Vs) / (1 + α)
```

精确解是 `v(t)=Vs(1-e^{-t/(RC)})`。测试首先对后向欧拉离散递推，再比较精确解；两者不得混为同一个 oracle。

### 3. 历史状态红线

`v_{n-1}` 在整个第 n 个时间步的 Newton 迭代中必须保持不变。只有第 n 步收敛后，才能把新解推进为下一步历史。

> 禁止让 `stamp()` 在 Newton 循环内更新器件内部历史；这会把“时间步”和“非线性迭代”混为一层。

### 第 4 档：`Inductor` 设计闸门 + RL

电感不允许直接照抄电容。先比较两种方案：

1. Norton companion：`i_n = i_{n-1} + (dt/L)v_n`，需要独立管理历史电流。
2. MNA 支路未知量：把 `i_L` 放入解向量，后向欧拉约束为

```text
v_pos - v_neg - (L/dt)i_n = -(L/dt)i_{n-1}
```

第 2 种方案的优点是历史电流直接存在 `x_prev`中；代价是必须把当前“电压源数”抽象成更一般的“支路未知量数”。用户必须选择方案并说明权衡。

绿灯：电感单步 stamp 图案正确；RL 电流轨迹与后向欧拉递推一致；原回归全绿。
