## 二、任务说明书（按序，闸门优先于一切）

### 1. `CurrentSource`（src/devices/，新文件记得加进 `src/CMakeLists.txt`）

电流源 I，正方向 a → b，只碰 b，两次 `add_to_b`：

```
b(a) −= I      b(b) += I
```

单测：落点/符号；接地端跳过；与电阻共存时 A 不被污染。

### 2. `VoltageSource`

电压源 V（a 为正端），构造时收"自己是第几个电压源"，用 `branch_index` 拿到支路下标 k，5 次写入：

```
A(a,k) += 1    A(b,k) −= 1        (KCL 行：节点方程里加支路电流)
A(k,a) += 1    A(k,b) −= 1        (约束行：v_a − v_b = V)
b(k)   += V
```

**⚠️ 本任务最需要盯的地方**（Day 2 回执点名）：这 5 次写入是混合坐标（节点行×支路列），
是用户理解最新、实操最少的部分。**盯紧符号配对：`A(a,k)` 与 `A(k,a)` 必须同源约定**——
a 端在 KCL 行取 +1，则约束行 a 端也是 +1。节点坐标那一维走 `add_to_A` 会被跳地逻辑处理吗？
——不会，混合坐标必须走 raw 方法，节点→下标的换算（跳地、减一）得在 stamp 里自己做或让用户想清楚。
这是他最可能卡住的点，卡了提示方向，别代写。

单测：`dim() == 节点数−1+源数`；约束行/列 5 个落点；接地端（b=0）时只剩 3 次写入。

### 3. 端到端闸门（最高优先级，做到这就赢了）

手工构造闸门电路（不需要解析器）：

`V1 = 10V`（节点1 → 地），`R1 = 1kΩ`（节点1 → 节点2），`R2 = 4kΩ`（节点2 → 地）

流程：三个器件 stamp 进 `MnaSystem` → `lu_decomposition` → `lu_solve` → 断言。

| 量 | 期望值 | 独立校验 |
|----|--------|---------|
| v1 | 10 V | 等于源电压 |
| v2 | **8 V** | 分压公式 Vs·R2/(R1+R2) ✓ |
| i_V1 | −2 mA | −Vs/(R1+R2) ✓ |

浮点断言用 `EXPECT_NEAR`（容差 1e-9 量级即可）。三个量都断言，不只 v2。
