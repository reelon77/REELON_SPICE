## 三、数学结果与接口决策

### 1. 瞬态上下文

最终选择显式：

```text
TransientContext { dt, const x_prev&, time }
```

并通过 `Device` 的第三个虚函数重载传入。没有叠加 Newton 组装回调：当前只有一套固定器件遍历，额外抽象尚无足够收益；回调保留为未来出现第二种组装策略时的升级点。

### 2. 电容后向欧拉

定义电容电压 `v=v_p-v_q`、电流方向 `p -> q`：

```text
i_n = (C/dt)(v_n-v_prev)
G_eq = C/dt
I_hist = -G_eq*v_prev
```

独立主例：`C=2F、dt=0.5s、v_prev=3V`，得到：

```text
G_eq = 4S
I_hist = -12A
A = [[4,-4],[-4,4]]
b = [12,-12]
```

单位 RC：`Vs=R=C=1、dt=0.1、v_0=0`，首步 `v_1=1/11V`，后向欧拉闭式为：

```text
v_n = 1-(10/11)^n
```

连续精确解 `1-exp(-t)` 只用于验证减小步长时的收敛趋势，不与离散 oracle 混为一谈。

### 3. 固定步长轨迹

- 轨迹包含 `{t=0, initial_x}`。
- `t_step>0`、`t_stop>=0`、初始解维度必须正确。
- 令 `q=t_stop/t_step`，仅当 `|q-round(q)|<=1e-12` 时接受固定网格。
- 使用整数步号生成时间，不靠浮点累加决定循环终点。
- Newton 失败直接向外抛异常，不返回部分成功轨迹。

### 4. 电感后向欧拉

选择 MNA 支路未知量方案，不采用需要独立隐藏历史的 Norton 方案。定义 `i_L` 方向 `p -> q`：

```text
v_p-v_q-(L/dt)i_n = -(L/dt)i_prev
```

其代价是每个电感增加一个未知量；收益是历史电流天然位于 `x_prev[k]`，DC 时还能用同一支路精确表达理想短路。

独立主例：`L=2H、dt=0.5s、i_prev=3A`，得到 `L/dt=4ohm`、`b(k)=-12V`。

单位 RL：`Vs=R=L=1、dt=0.1、i_0=0`，闭式为：

```text
i_n = 1-(10/11)^n
[v1,v2,iV,iL] = [1,1-i_n,-i_n,i_n]
```

### 5. parser 闭环

- C/L 器件行均为 4 个 token，数值复用 `string2double`。
- `.tran t_step t_stop` 为 3 个 token，parser 层要求两个时间参数均为正。
- V/L 按网表出现顺序共享零基 `num_branch_unknowns`；C 不增加 MNA 维度。
- 错误 token 数、非法数值和非正 C/L/时间参数均保留网表行号。
- parsed RC 的两步手算值为 `[2,0.4,-0.8]`、`[2,0.72,-0.64]`。
- parsed RL 故意令 L 先于 V，未知量顺序为 `[vout,vin,iL,iV]`，两步手算值为 `[1,2,0.5,-0.5]`、`[0.5,2,0.75,-0.75]`。

## 四、历史状态所有权与推进时机

- `transient_solve` 独占一份可变的局部 `x_prev`。
- 第 n 步把 `x_prev` 同时作为 Newton 初值和只读历史上下文。
- Newton 内只更新当前迭代量 `x`；同一份 `TransientContext` 和 `x_prev` 在该时间步的所有迭代中冻结。
- Capacitor 从 `x_prev` 读取历史节点电压；Inductor 从 `x_prev[k]` 读取历史支路电流。
- 只有 Newton 正常收敛返回后，时间步进层才追加轨迹点并令新解成为下一步历史。
- Newton 抛异常时历史不推进；stamp 和器件内部均不保存、修改时间历史。

因此：一个时间步内 Newton 即使更新 `x` 多次，`x_prev` 也更新 0 次；每个成功时间步结束后才更新 1 次。
