## 二、任务说明书

**目标**：`src/core/` 下完成稠密 Matrix + 带部分选主元的 LU 分解与求解，四个验证用例全过。

**文件布局**（新文件记得加进 `src/CMakeLists.txt`）：

```
src/core/Matrix.h / Matrix.cpp   稠密矩阵，std::vector<double> 底层，行优先
src/core/LU.h / LU.cpp           LU 分解 + 求解
```

**Matrix 最小接口**：`Matrix(n, m)` 全零构造、`operator()(i, j)` 读写、`rows()/cols()`。向量先用 `std::vector<double>`，不封装。别过度设计。

**LU 算法要点**（Doolittle + 部分选主元，就地分解）：

1. 对第 k 列（k = 0..n−1）：在 k..n−1 行找 |A(i,k)| 最大的行 p，交换第 k、p 行，用置换向量 perm 记录（不搬 P 矩阵）
2. 若 |A(k,k)| < 1e-12 → 奇异，报错（对应后续"电路没接地/悬空节点"场景，必须有这个分支）
3. 消元：对 i > k，乘数 m = A(i,k)/A(k,k) 存回 A(i,k)（L 的位置），A(i,j) −= m·A(k,j)
4. 求解：按 perm 重排 b → 前代 Ly = Pb（L 对角隐含 1）→ 回代 Ux = y

**验证用例**（答案已手推，必须全过）：

1. 2×2：A = [[2, 1], [1, 3]]，b = [5, 10] → x = [1, 3]
2. 3×3 触发选主元：A = [[0, 2, 1], [1, 1, 1], [2, 0, 1]]，b = [4, 6, 7] → x = [2, 1, 2]（首列主元为 0，不选主元必挂）
3. 奇异：A = [[1, 2], [2, 4]] → 报错，不是 NaN
4. 上午的 G 矩阵：[[0.001, −0.001], [−0.001, 0.0015]] 为奇异（未接地拉普拉斯）→ 报错。此用例衔接上午理论与今天代码

**预埋的坑（用户卡住时提示方向，别直接给答案）**：

- 选主元换行时，已算好的 L 部分要跟着换（就地存储整行 swap 自动正确；L/U 分开存会漏）
- 重排的是 b 不是 x，回代完不要再排一次
- 用户上午的已知弱点：**累加写成赋值**（stamp += 连错三次），review 时留意同类错误

**可选讨论点**（用户若问再展开）：分解/求解分离的接口设计（牛顿迭代会复用同一分解多次求解不同 b？不会——每次迭代矩阵都变，但瞬态定步长线性电路会复用）、复杂度 O(n³)/O(n²)、为什么部分选主元数值稳定。
