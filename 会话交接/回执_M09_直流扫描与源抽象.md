## 二、第 0 档设计闸门

### D0-01：分析请求表示

最终选择：使用具名 struct 和 `std::variant`：

```cpp
struct OperatingPointAnalysis {};
struct TransientAnalysis {
    double t_step;
    double t_stop;
};
struct DcSweepAxis {
    std::string source_name;
    std::size_t device_index;
    double start;
    double stop;
    double step;
};
struct DcSweepAnalysis {
    DcSweepAxis primary;
    std::optional<DcSweepAxis> secondary;
};
using AnalysisRequest = std::variant<
    std::monostate,
    OperatingPointAnalysis,
    TransientAnalysis,
    DcSweepAnalysis>;
```

`Circuit` 只保存一个 `analysis`，不保留可独立修改的 `AnalysisType/t_step/t_stop/dc_*` 双份状态。parser、controller 和测试全部迁移到该单一真源。

拒绝方案：继续扩展 enum 加裸字段。原因是它可表达“`.op` 却携带有效 `.tran/.dc` 参数”等矛盾状态，且后续 `.ac` 会继续放大该问题。

### D0-02：扫描源身份

锁定不变量：

```text
circuit.device_names.size() == circuit.devices.size()
device_names 按网表出现顺序保存、全小写、全局唯一
DcSweepAxis.source_name -> DcSweepAxis.device_index -> IndependentSource
```

- tokenizer 已统一转小写；parser 在每个器件成功构造时同步写入 `device_names`。
- 重名在当前器件行拒绝，因此 `R1/r1` 和跨类型的同名均不合法。
- `.dc` 先保留规范化源名与行号，读到 `.end`/EOF 后再解析为 `device_index`，因此支持前向引用。
- 不用 `branch_names` 定位，因为独立电流源没有 MNA 支路未知量；controller 不重新解析网表。

### D0-03：非破坏式源覆盖

最终选择：引入 `IndependentSource : Device`，公开只读 DC 值和 `clone_with_dc_value(double)`。每个扫描点：

1. 从 `Circuit::devices` 建立非拥有 `Device*` 视图；
2. 只克隆一个或两个被扫源；
3. 在当前点的视图中替换对应位置；
4. 源副本由当前调用的 `std::unique_ptr` 拥有，裸指针不逃逸。

拒绝方案：

- setter/`const_cast` 修改后再恢复：异常、重入和重复调用下容易污染 `const Circuit`。
- 每点深拷贝整个 Circuit：所有器件都需要 clone，与“只改一个源值”的成本和语义不匹配。

### D0-04：扫描序列与结果契约

结果锁定为：

```cpp
struct DcSweepPoint {
    std::vector<double> source_values; // 严格为 1 或 2 个
    std::vector<double> x;
    int newton_iterations;
};
struct DcSweepAnalysisResult {
    std::vector<std::string> source_names; // 严格为 1 或 2 个
    std::vector<DcSweepPoint> points;
};
```

- 扫描值由单一函数按整数步号 `start + k * step` 生成，使用尺度相关的浮点容差判断边界，不通过反复累加生成下一点。
- 必须为有限数；`step != 0`；升序必须正 step，降序必须负 step；`start == stop` 允许任意非零有限 step，仅生成一点。
- 不整除时只产生不越过 stop 的点，不强行附加 stop，也不缩短末步。
- 双源严格按 secondary（source2）外层、primary（source1）内层写入 `points`。
- 第一点使用全零初值，其后每点使用结果序列中紧邻成功点的 `x`；不在外层边界重置。
- 任一点失败即抛错，错误包含点序号和当前源值，不返回部分结果。

CSV 表头锁定为 `sweep(<source>)`，其后沿用现有稳定的节点电压/支路电流列顺序。

### D0-05：兼容与错误契约

- `.op/.tran` 的物理结果、公开 result 类型、writer 文本/CSV 和 CLI 退出码保持不变。
- 同一网表的第二个 `.op/.tran/.dc` 统一拒绝，错误含当前行、当前指令和第一指令行。
- `.dc` 分别拒绝 token 数、非法数值、非有限数、零/反向 step、未知源、非独立源、重复源和器件重名；parser 错误包含 `.dc` 行号与相关 token/源名。
- writer 在首字符前校验源名数、点源值数、非空点集和解维度。
- controller 对手工构造的非法 Circuit 继续做防御性检查；扫描点失败的异常向 CLI 传播为退出码 1。
