## 三、任务说明书：牛顿迭代 + 二极管

### 数学结构（用户的语言）

非线性 DC 就是解 F(x) = 0：KCL 里出现了二极管的非线性电流 I(v) = Is·(e^(v/Vt) − 1)。
牛顿：每步解 J(xᵏ)·Δx = −F(xᵏ)。**companion model 是同一件事的电路化表述**——把牛顿步伪装成一个线性电路：

- 在当前迭代点 v 处线性化：g_eq = dI/dv = (Is/Vt)·e^(v/Vt)，I_eq = I(v) − g_eq·v
- 二极管这一步的 stamp = **一个电导 g_eq（4 个 `+=`，同电阻）+ 一个电流源 I_eq（2 个 b 写入）**
- 于是"牛顿迭代"="每轮用当前解重新组装线性 MNA → `lu_solve` → 得下一个迭代点"，外层循环判 ‖Δx‖ < tol

用户能自己推出 g_eq/I_eq 公式（就是一阶泰勒），**让他推，你只对答案**。

### 关键设计决策（引导用户自己做，这是面试深挖点）

`Diode::stamp` 需要**当前迭代解**，而现有 `stamp(MnaSystem&) const` 拿不到。怎么改？
候选方向（都合法，让用户权衡后自选，你补充各自代价）：

- `stamp(MnaSystem&, const std::vector<double>& x)` 全体改签名——线性器件多收一个不用的参数
- `Device` 下分 `NonlinearDevice` 子类/第二接口——层次多一层，牛顿循环要区分两类器件
- 器件持有迭代点的引用/指针——生命周期问题，慎选

不管选哪条，**Resistor/V/I 源的行为不能变**（已有 43 个测试守着），这正是"开闭原则"的活素材。
另一个必须想清楚的点：**每轮迭代 A 和 b 都要清零重组装**（线性部分也要重新盖章）——初版最容易犯的错是往上一轮的矩阵上继续 `+=`。

### 收敛循环（solver 层，建议放 `src/solver/`）

骨架：初值 x⁰（全 0 即可）→ 循环 { 清零 → 全体器件 stamp → lu_solve → 判 ‖xᵏ⁺¹ − xᵏ‖∞ < tol → 更新 }，
带最大迭代次数保险（建议 300，理由见下面的实测数据），不收敛抛异常或返回状态。

## 四、验证用例（主会话已实算，数值可信）

### 电路

`V1 = 5V`（节点1 → 地），`R = 1kΩ`（节点1 → 节点2），`D`（节点2 → 地，正端接节点2），
`Is = 1e-12 A`，`Vt = 0.025852 V`。

### 真解（二分法解 (Vs−v)/R = Is(e^(v/Vt)−1)，200 次迭代收敛）

| 量 | 值 |
|----|-----|
| v2（二极管电压） | **0.574191503 V** |
| 回路电流 | 4.425808 mA |

端到端断言建议 `EXPECT_NEAR(x[1], 0.574191503, 1e-6)`（v1 = 5V 也一并断言）。

### 牛顿行为实测（判据 |Δv| < 1e-12，你可以直接引用这些事实）

- **初值 v⁰ = 0：178 次迭代收敛**。不是 bug！第一步 g_eq ≈ Is/Vt ≈ 4e-11 几乎为 0，解直接跳到 ≈ 5V；
  之后指数项主导，每步只降约一个 Vt（≈ 0.026V），(5 − 0.574)/0.026 ≈ 170 步——爬坡是指数非线性的固有行为。
- **初值 v⁰ = 0.9：18 次迭代收敛**。
- 本电路特意选了安全数值：最大指数 e^(5/Vt) ≈ e^193 ≈ 5e83，double 装得下（上限 ~1.8e308），**不会溢出**。
  Vs 换成 20V 就会溢出——这是为什么真 SPICE 要做 limiting/阻尼。**今天不实现**，但让用户把
  "178 步 vs 18 步 + 为什么要 limiting"记进面试素材（学习清单里的"刚性/收敛性"一行）。
- 用户实现的迭代次数与 178 差个位数属正常（浮点路径不同），量级不对（比如 3 次就"收敛"或 300 次不收敛）才是 bug。

### 单测建议（从小到大，每绿一档提交一次）

1. **Diode 线性化单点检查**：v = 0.5 时 g_eq = 9.708141378e-3 S，I_eq = −4.603095819e-3 A（主会话实算）。
2. Diode stamp 落点：g_eq 四个位置 + I_eq 两个 b 位置，对称性。
3. 收敛循环烟囱测试：纯线性电路（拿闸门电路）走牛顿循环，**1~2 次迭代即收敛且答案仍是 8V**——
   这一步能单独验证"清零重组装"没写错，强烈建议不要跳过。
4. 端到端：二极管电路 → v2 ≈ 0.574191503，迭代次数 ∈ [10, 300]。
5. 不收敛路径：max_iter 设小（如 5）时正确报不收敛。
