## 1. 电路的数学抽象

**电路 = 图 (graph)**:

- 节点 (node) = 未知量,每个节点一个待求实数 $v_i$,叫节点电压;
- 支路上的器件 = 节点间的约束关系,每个器件贡献方程项。

仿真器的问题:给定拓扑 + 器件参数,求所有节点电压 → **解方程组**。线性器件 → 线性方程组 $Gv = b$(下午的 LU 解的就是它)。

**地节点 (ground, 节点 0)**:规定 $v_0 = 0$,电压参考零点。

为什么必须有:所有器件方程只含**电压差** $v_a - v_b$,故解空间沿 $(1,1,\dots,1)$ 方向平移不变 → 方程组奇异。钉死 $v_0=0$ 是固定规范 (gauge fixing),消掉这个一维自由度。

## 2. 欧姆定律

电阻:两端点 $a,b$,参数 $R>0$(单位 Ω)。约束:

$$i = \frac{v_a - v_b}{R} = G\,(v_a - v_b), \qquad G = \frac{1}{R}$$

- $i$:流过电阻的电流,**约定从 $a$ 流向 $b$ 为正**;
- $G = 1/R$:电导(单位 S)。写方程和代码都用 $G$,保持线性叠加形式。

⚠️ 唯一的坑:符号约定的一致性。方向是人为规定的,定了就全程统一——之后 `stamp()` 代码 90% 的 bug 出在正负号。

**口算题**:$v_a = 5\text{V},\ v_b = 2\text{V},\ R = 1\text{k}\Omega$。求 $i$ 及方向。

**答案**:$i = (5-2)/1000 = 3\text{mA} > 0$,从 a 流向 b。

## 3. KCL 基尔霍夫电流定律

**每个节点:流出电流之和 = 0。** 即流量守恒(flow conservation / 散度为零),电荷不在节点堆积。

组装流程:

- 每个**非地节点**列一条 KCL 方程;n 个非地节点 → n 条方程 → n 个未知电压,方程组封闭;
- 地节点不列方程($v_0 = 0$ 已知)。

各类器件在节点 $a$ 的 KCL 方程里的贡献:

| 器件 | 贡献 | 位置 |
|---|---|---|
| 电阻 $R$,接 $a,b$ | 流出项 $\dfrac{v_a - v_b}{R}$("自己减对方") | 左边(含未知量) |
| 电流源,注入 $a$ 电流 $I$ | 注入即"流出 $-I$",移项后为 $+I$ | 右边(常数 → $b$ 向量) |

单节点模板:

$$\sum_{\text{电阻}} \frac{v_a - v_b}{R} = \sum \text{注入 } a \text{ 的电流源}$$

**练习**:节点 1 为唯一非地节点;电流源注入 $I = 6\text{mA}$;$R_1 = 1\text{k}\Omega$ 接节点 1 与地;$R_2 = 2\text{k}\Omega$ 接节点 1 与地。列 KCL 方程,解出 $v_1$。

**答案**:$\dfrac{v_1}{1000} + \dfrac{v_1}{2000} = \dfrac{6}{1000} \Rightarrow \dfrac{3v_1}{2000} = \dfrac{6}{1000} \Rightarrow v_1 = 4\text{V}$。
验证守恒:流出 $R_1$ 4mA + 流出 $R_2$ 2mA = 注入 6mA。✓

## 4. 分压电路手推(验证闸门)

新器件:**理想电压源**,强行钉死两端电压差,不管流过多少电流。

电路:12V 电压源(另一端接地)→ 节点 1;$R_1 = 1\text{k}\Omega$ 接节点 1、2;$R_2 = 2\text{k}\Omega$ 接节点 2、地。

**简化处理**(严谨版是 Day 3–4 的 MNA 扩展维):电压源一端接地 → 直接把 $v_1 = 12\text{V}$ 当已知量,不给节点 1 列 KCL。剩一个未知量 $v_2$、一条方程。

**闸门题**:① 对节点 2 列 KCL;② 解出 $v_2$;③ 说清每一项来自哪个器件、符号为何如此。

**答案**:$\dfrac{v_2 - 12}{1000} + \dfrac{v_2 - 0}{2000} = 0 \Rightarrow \dfrac{3v_2 - 24}{2000} = 0 \Rightarrow v_2 = 8\text{V}$。✓(闸门通过)

符号解读:代入 $v_2 = 8$,R1 项 $= -4$mA(流出为负 = 实际流入),R2 项 $= +4$mA。4mA 从节点 1 经 R1 流入节点 2,再经 R2 流出到地。写方程时无脑"自己减对方",方向由解的符号自动给出 → 这就是可机械化的原因。

另:比例法($v_2 = 12 \times \frac{R_2}{R_1+R_2} = 8$)只适用于两电阻串联特例;KCL 法对任意拓扑成立且可机械化。

## 5. 从 KCL 到矩阵形式:$Gv = b$ 与 stamp

把所有 KCL 方程按未知量整理 → 线性方程组 $Gv = b$:$G$ 电导矩阵(对称、对角占优),$v$ 节点电压向量,$b$ 电流源注入。

**G 可以直接组装,不必先列方程**。每个器件贡献固定模式(= stamp,盖章):

- **电阻**($g = 1/R$,接节点 $a,b$):
  $$G[a][a] \mathrel{+}= g,\quad G[b][b] \mathrel{+}= g,\quad G[a][b] \mathrel{-}= g,\quad G[b][a] \mathrel{-}= g$$
  原因:$a$ 的 KCL 中此电阻贡献 $g(v_a - v_b) = +g \cdot v_a - g \cdot v_b$。某端接地 → 该行该列不存在,只剩对角项。
- **电流源**(注入节点 $a$ 电流 $I$):$b[a] \mathrel{+}= I$。

内核主循环:`for (器件) 器件.stamp(G, b); solve(G, v, b);` —— stamp 接口的数学本质。

**收尾练习**:分压电路中把 $v_1$ 也当未知量(暂不管电压源),stamp 两个电阻,写出 2×2 的 $G$ 矩阵。

**答案**:

$$G = \begin{pmatrix} \frac{1}{1000} & -\frac{1}{1000} \\ -\frac{1}{1000} & \frac{3}{2000} \end{pmatrix}$$

对角元 = 该节点所挂全部电导之和($G[2][2] = g_1 + g_2$,两次盖章**累加**)。sanity check:对称 ✓,对角占优 ✓。

## 上午总结(带回主会话)

**成果**:抽象(电路=图→方程组)、地节点=规范固定、欧姆定律、KCL 列方程、分压电路手推 8V(闸门通过)、电阻/电流源 stamp、内核主循环 `for(器件) stamp; solve;`。

**课后加深(用户主动推出的)**:

- 发现 2×2 练习是"无源死电路"(节点 1 的 KCL 缺电压源电流项),解全零是正确的;
- 抽象出局部性:KCL 只涉及直接邻居 → $G[i][j] \neq 0 \iff$ 直连或对角 → G = 带权图拉普拉斯(对称、半正定、行和为零;接地删行列后正定),稀疏性由此而来。
